# The Cloudflare R2 provider

Holds the library in an R2 bucket, read by the app through a Worker binding and written by the sync tool through the wrangler CLI. No access keys to create: it reuses whatever login wrangler already has.

## Configuration

```json
{
  "storage": {
    "provider": "r2",
    "bucket": "books",
    "jurisdiction": "eu",
    "worker": "apps/bookshelf"
  }
}
```

| key | |
| --- | --- |
| `bucket` | the R2 bucket. Leave it out and it is read from the Worker's `wrangler.jsonc` |
| `jurisdiction` | data residency, e.g. `eu`. Omit for the default |
| `worker` | where wrangler runs, so it finds the right `wrangler.jsonc` |

Give both `bucket` and a `wrangler.jsonc` that disagree and the provider says so
before uploading anything the app would not be able to see.

## Two files carry a deployment

Both are checked in with this project's own values, and both are meant to be
edited:

| file | change |
| --- | --- |
| `bookshelf.config.json` | `storage.bucket`, and `storage.jurisdiction` — delete that key unless you want EU data residency |
| `apps/bookshelf/wrangler.jsonc` | `name`, and the `r2_buckets` entry to match the above |

```bash
npx wrangler login
npm run sync -- --create   # creates the bucket, then uploads to it
npm run deploy
```

## What it cannot do

R2 over wrangler cannot enumerate: wrangler exposes only get, put and delete for
objects. So this provider implements `create` and leaves `list` and `removeAll`
undefined, and the sync works out the previous contents from the catalog it
published last time — exact for a bucket only it manages, blind to anything put
there by other means, and `--force` says so rather than implying it cleared more
than it did.

## Publishing locally

`npm run sync -- --local` targets the local miniflare bucket, which is what
`npm run dev` and `npm run preview` read. The provider declares
`concurrency: 1` there, because every local invocation boots a miniflare
runtime that takes an exclusive lock on the state file and parallel writes fail
with `SQLITE_BUSY`.
